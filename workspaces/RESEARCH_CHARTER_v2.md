## 5. Stage 流程（極簡）

| Stage | 做什麼 | 殺線 |
|-------|--------|------|
| **0** Brief | session / side / TF / entry 代理 / stop / **falsify** | 寫不出 falsify → 不開工 |
| **1** Observe | 1–3 日深讀 + ≤1 月粗掃 | 只有「感覺事件」無機械規則 → 停 |
| **2** Path | emit→score；至多 **一輪** 小 grid | 單窗過不了 soft bar → park；**禁止二刷同窗** |
| **3** Edge | 兩段窗 + 一式 exit + net@5pt | n 過稀 / net 對摩擦無意義 → kill + 墓誌銘 |
| **4** Ops | 人類 Pick 後才 plugin；Pilot 人類決定 | Agent 禁止 `simulation: false` |

**預設 split（Stage 3，BRIEF 可覆寫）**：探索/訓練偏 **2025**；OOS 偏 **2026Q1**（精神沿用 DATA_SPLIT，不強制舊 Holdout 全文儀式）。

**Holdout v2 厚尾 / Class Appeal / Preflight 長鏈**：legacy optional。  
**保留**：資料切分防偷看、摩擦、人類 Go Pilot。
