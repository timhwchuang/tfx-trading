## 1. 合約是尺子，不是背景設定

微台（TMF / TMFR1）要能脫口而出：

| 事實 | 數字 |
|---|---|
| 1 點 | **NT$10** |
| tick | **1 點**（小台 50、大台 200 不是同一把尺） |
| 原始保證金 | config **35,050** NT |
| 指數 23,000 時 3 點 | **0.013%**，比一檔報價跳動還小 |
| 日盤高低 P50 / P90 | **243 / 421 點** = 2,430 / 4,210 NT ≈ 保證金的 **7% / 12%** |

寫停損前先換算：這是風險單位，還是雜訊？**3/5/8 過不了這關，不該進 `GridSpec`。**

## 2. 費用先變成「點」，再談 R

來回先算成點，不是事後扣 NT$：

`雙邊稅 0.00002 × 契約價值 + 雙邊手續費`

這張 tape：中位日盤收 22,585 → **4.9 點**；價 23,000 → **4.92 點 ≈ 49 NT**。
停損滑價 1 tick、強平 `flatten_slippage_ticks=2` 另計。

**規則：R ≤ 來回費用 = 不是交易。**

3 點停、2R = 6 點、費用 5 點——沒有期望值空間。這是算術，不是回測結果。

## 3. 時段生理（台指期不是 24h 均質噪音）

1m 振幅，同一段 IS。開盤窗最肥，但策略不碰；**可交易時段裡 09:15–10:30 最肥**。

| 時段 | 1m P50 | 1m P90 | 記住什麼 |
|---|---:|---:|---|
| 08:50–09:15（開盤禁做） | **19** | 39 | `no_trade_before=09:15` 是對的 |
| 09:15–10:30 | **14** | 28 | 一天裡最容易掃停的可交易窗 |
| 11:00–13:00 | **8** | 16 | 限價容易掛著不成交 |
| 13:30–13:45 | **8** | 18 | 強平／結算流動，不該還在等 2R |
| 夜盤 | **6** | 15 | 1m 較瘦；`prev_night` 仍是日盤策略輸入。缺分鐘會讓日盤 sweep 假死／假活 |

再加上（產品知識，不是參數）：**結算日整天不做**、換月（TMFR1 13:31、無 back-adjust）、漲跌停。行為跟普通日不是同一分布。

## 4. 波動用百分位，三層不准混

| 層 | 這張 IS | 用途 |
|---|---|---|
| 費用地板 | ~**5 點** | 低於這個不進 |
| 雜訊地板 | 日盤 1m **10 / 23**；arm 窗 **10 / 21**；5m 振幅 **25 / 55**；ATR(14) 串接 **30 / 48** | buffer、同根 1m 掃、min_r 要能指回這裡 |
| 結構距離 | A′ 停在 sweep 極值時 join R P50 **119**（多 162／空 105） | 停損放哪；2R≈238 要跟日振幅 243 對過 |

v1 把三層壓成 `{3,5,8}`。那不是調參失敗，是沒這張尺。
`min_r=15` 只是 3× 費用，**不是**雜訊地板。

---

## 5. 成交假設比訊號還先

限價碰到 ≠ 成交。5m FVG 回補常是長針掃過：最賺的單最容易沒排到，最虧的單 100% 成交。

先規定 **停損優先、同根進場即停、conservative trade-through**，再讓策略適應。
不准為了少 `entry_stopped` 把停損晚一棒掛——那是在 1m 上謊報風險。

第一輪 cons≡opt：那批單不是差在成交模型，是單本身沒有 edge 空間。

---

## 6. 幾何先於掃描

空單進 FVG top +「停損取較近者」是 **v1 恆等式**（R 恆等於 `stop_buffer`）；碰上 1m 中位 10 點只是死得更快。**現行停損在 sweep 極值。**

先在紙上算一筆的 entry／stop／R，再寫 code。單元測試鎖死「禁止 R==buffer」。
11 小時 grid 測不出恆等式。

結構停損若在 sweep 極值，R 變成 ~100 點，2R 跟日振幅 243 對過。這也是幾何，不是優化。

---

## 7. 射頻是產品約束

日盤 5m、一次一單、結算不做、09:15 才開。一年能有幾槍要**先數過再寫策略**。

IS 普查：bias+sweep+event+FVG≥15 unique **17**，低於 `MIN_IS_TRADES=30`。
稀有 setup 不能靠掃 216 格變出統計。樣本不夠是 `no_go`，不是放寬閘、也不是再加 RSI。
